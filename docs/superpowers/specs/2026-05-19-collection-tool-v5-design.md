**Date:** 2026-05-19

## 1. Overview

Improve the body of batch dunning emails generated by `buildBatchMailto`. Instead of the current single-line-per-document format, display documents in a fixed-width plain-text table with a column header row, two divider lines, and a `總計` / `总计` / `Total` summary row showing the summed overdue amount. The per-row single-document `buildMailto` is unchanged.

---

## 2. Scope

| Function | Change |
|----------|--------|
| `buildBatchMailto(groups)` | Replace `lines` construction with table builder |
| `buildMailto(group)` | No change |

---

## 3. Table Format

The table is plain text (embedded in a `mailto:` URL body). Fixed-width space padding aligns columns.

### 3.1 Column Widths

| Column | Width (chars) | Alignment |
|--------|---------------|-----------|
| Document # / 文件編號 | 22 | Left |
| Due Date / 到期日 | 14 | Left |
| OD Days / 逾期天數 | 12 | Left |
| Amount / 逾期金額 | — | Right (no fixed width; last column) |

Divider line: 53 `─` characters (covers all four columns).

## 4. Total Row Calculation

- **Amount:** Sum of `Math.abs(Number(g.localAmt || 0))` across all groups in the customer batch.
- **Currency:** `localCurr` of the first group (all groups for one customer share the same currency).
- **Format:** Same comma-formatted integer as individual rows — `{currency} {amount}`.
- **Label:** `總計` (0073) / `总计` (0038) / `Total` (fallback). No item count displayed.

---

## 5. Padding Helper

A new `pad(str, width)` helper pads a string to exactly `width` characters with trailing spaces:

```js
function pad(str, width) {
  const s = String(str == null ? '' : str);
  return s.length >= width ? s + '  ' : s + ' '.repeat(width - s.length);
}
```

Used to build each column in header, data rows, and total row.

## 6. Full Email Body Structure (繁體中文)

```
{customer} 您好，

謹此提醒，以下應收帳款已逾期，煩請盡快安排付款：

{table}

如有任何疑問，歡迎隨時與我聯繫。

謝謝！
Huang Fan
```

Where `{table}` is the header + divider + data rows + divider + total row block, with `\n` between each line.
