AR Collections Workbench

Greater China Collections — CC0038 · CC0073 · CC0074 · Feature Summary

🚀 Live site: https://hfrandb.github.io/ar-collections-workbench/  ·  Data as of 2026-08-03  ·  1,007 sold-to accounts
Access: Open the launcher at https://hfrandb.github.io/ar-collections-workbench/ — three tiles open each page in a new window. Each team member works on their own copy; edits save to their own browser (localStorage).
📊 Summary Page

KPI Bar

  • Total Past Due by entity (CNY / TWD / HKD)
  • PD >90d amounts and account counts
  • Term Risk & EHF Impact account counts
  • Updates dynamically with all filters

EHF Global Exposure

  • EHF Now / Month-End Aug 31 / Q-End Sep 30
  • Per entity (CC0038 ÷1.06 / CC0073 ÷1.05 / CC0074 ÷1.00)
  • Formula: Posting Date +30 = EHF Due; OD >90d triggers EHF

Risk Overview Grid

  • Per-entity Term Risk / EHF Impact / OB Risk counts
  • Total PD amount and account count per CC

💰 Income Collected

  • Live total of payments marked Paid by the collector
  • Syncs with Worklist via browser localStorage
  • Shows CNY / TWD / HKD totals + doc counts
📈 Activity Page

Daily Edit Tiles

  • Total Edits, Today, Unique Docs Touched, Days Active

Bar Chart

  • Edits per day — last 30 days
  • Today highlighted in blue

Edit Log Table

  • Every cell change: timestamp, entity, BP#, Doc#, field, old/new value
  • Filters: date / field type / entity
  • Export CSV / Clear history
📋 Worklist Page

Account Cards

  • 1,007 accounts grouped by Sold-to Party
  • Sorted by AR amount largest first
  • 3 entity sections: CC0038 / CC0073 / CC0074
  • Max DPD, collector tag, contact emails
  • Aging bar: 1–30d / 31–60d / 61–90d / >90d
  • EHF Now / ME / QE per account

Risk Tags

CRITICAL >365d HIGH >90d MEDIUM >30d WATCH ⚠ Term Risk EHF Impact ⛔ OB Risk
  • Term Risk: DPD >365 or Termination Status in report
  • EHF Impact: DPD >90 or EHF II Status in report
  • OB Risk: DPD >60 or Order Block flag set

Cascading Filters

  • Entity (CC0038 / CC0073 / CC0074)
  • Priority: Critical / High
  • Risk: Term Risk / EHF Impact / OB Risk (toggles, all stack)
  • Collector dropdown — narrows by entity + customer
  • Customer dropdown — narrows by entity + collector
  • Free-text search by customer name

📂 Data Source Panel

  • Drag-and-drop Excel files — auto-detects file type
  • SharePoint URL paste with auto-link conversion
  • Animated progress bar (chunked async parsing)
  • SheetJS bundled locally — works offline
  • Refreshes all cards, filters, contacts, and unblock data
▸ Document Details (expandable inline under each card)

Editable Fields per Doc#

  • FC Month — dropdown (Aug / Aug-Risk / Sep-Risk etc.)
  • Customer Payment Process — dropdown (Standard / PO/PR / Paid etc.)
  • Current Status — free-text, pre-filled from report
  • 💾 Save Edits (localStorage) · 📥 Export Edits CSV

Mark Paid

  • Button per doc row — strikethrough + green Paid badge
  • Auto-triggers when CPP = "Paid" or "Paid to CDC"
  • Updates 💰 Income Collected bar instantly
  • Undo with one click

CDC Indicator CDC

  • Shown on doc# when bill-to = China Datacom Corporation
  • Reference only — does not affect filtering or sorting
  • 248 of 1,007 accounts have CDC as bill-to
